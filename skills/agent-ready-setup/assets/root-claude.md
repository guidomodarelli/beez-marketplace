## Regla de centralización de instrucciones

`AGENTS.md` es fuente canónica. Cuando usuario solicite agregar, modificar o eliminar contenido de este `CLAUDE.md`, aplicar cambio directamente en `AGENTS.md`.

Regla aplica también a cualquier `CLAUDE.md` en subdirectorio: usar únicamente `AGENTS.md` hermano del mismo directorio. No usar `AGENTS.md` de raíz ni de otro nivel. No editar directamente `CLAUDE.md` ni duplicar instrucciones entre archivos.
