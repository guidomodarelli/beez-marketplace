# Groot Queue

`groot-queue` monitorea y gestiona la cola de soporte de Groot en Jira.

Consultá la [guía canónica de instalación, configuración, diagnóstico y ciclo de vida](skills/groot-queue/knowledge/config/installation.md) para Claude Code, Codex, ACLI, MCPs, Grid Sharing y Fury Services/FuryDocs.

`setup` diagnostica el entorno; no instala, autentica, habilita, configura ni actualiza componentes sin aprobación explícita.
